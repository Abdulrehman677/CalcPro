# CalcPro — Smart Scientific Calculator

**Live Demo:** https://calc-pro-orpin.vercel.app

**GitHub Repository:** https://github.com/Abdulrehman677/CalcPro

A modern, feature-rich calculator built to make mathematical calculations easier, faster, and more intuitive. CalcPro combines a clean interface with powerful calculation tools in a responsive web application.

## Overview

CalcPro is a browser-based calculator application designed for students, developers, and anyone who works with mathematical calculations. It includes multiple calculation modes, interactive graphing, and dedicated mathematical tools in one place.

## Features

- **Scientific Calculator** — Perform advanced mathematical calculations.
- **Function Graphing** — Visualize mathematical functions on an interactive coordinate plane.
- **Equation Solver** — Work with mathematical equations.
- **Matrix Calculator** — Perform matrix-related operations.
- **Statistics Tools** — Calculate and analyze statistical values.
- **Calculation History** — Review previous calculations.
- **Responsive Interface** — Use the application across different screen sizes.
- **Modern UI** — Clean layout with a refined dark theme and gold accents.

## Getting Started

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/) (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Abdulrehman677/CalcPro.git
   ```

2. Open the project directory:

   ```bash
   cd CalcPro
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Production Build

To check TypeScript and create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

The generated production files are placed in the `dist` directory.
